# Shambhavi Shiragond — Premium Portfolio V2

Apple/Google-inspired responsive portfolio with:
- Custom Shambhavi "S" logo
- Dark/light mode with saved preference
- Animated GitHub-style activity panel
- Project showcase mockups
- Timeline
- Certifications
- Resume download button
- Responsive mobile navigation
- Scroll reveal animations
- GitHub and LinkedIn links

## Add your resume
Put your real resume in this folder and name it exactly:
`resume.pdf`

## Run
Open `index.html` or use VS Code Live Server.

## Deploy
Works with GitHub Pages, Vercel and Netlify.
